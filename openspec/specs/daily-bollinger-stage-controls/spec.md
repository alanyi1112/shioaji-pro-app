# daily-bollinger-stage-controls Specification

## Purpose
定義每日布林策略的收合設定、三階段獨立選擇、明確儲存與條件附註，以及結果階段名稱的可讀配色；保持既有篩選公式、來源政策與背景排程不變。
## Requirements
### Requirement: 每日策略須以收合的三階段按鈕呈現

每日區塊 MUST 預設收合並顯示已儲存啟用狀態、revision 與階段數；展開後 MUST 提供三個獨立 aria-pressed 按鈕，名稱為正在壓縮、準備突破、今日正式突破。尚無設定 MUST 預設全選，既有設定 MUST 保留原階段。

#### Scenario: 新設定與窄版
- **WHEN** 尚無每日設定且使用者展開 320px 選股面板
- **THEN** 三階段 MUST 全選、可換行且無水平溢位；收合不改設定、不發送 PUT

#### Scenario: 既有部分選擇
- **WHEN** 已儲存只選正式突破的每日設定
- **THEN** 開啟後 MUST 只選正式突破，不自動套用全選

### Requirement: 每日階段草稿須明確儲存且與手動草稿隔離

階段切換 MUST 只改每日草稿；儲存 MUST 沿用既有 criteria 其他參數與 expectedRevision，新設定 MUST 使用合法預設布林條件。空選擇 MUST 禁止儲存並提示；停用 MUST 沿用已存條件，即使手動／每日草稿非法仍可操作。失敗 MUST 保留原 profile 並顯示原因，不擅自下載、登入、訂閱或交易。

#### Scenario: 全部取消手動條件
- **WHEN** 手動條件全取消後使用者儲存每日階段或停用已存策略
- **THEN** 每日操作 MUST 不受手動非法草稿阻擋，且停用 MUST 不提交未儲存的 stages

#### Scenario: 儲存衝突
- **WHEN** 另一視窗更新 profile 導致 PUT 409
- **THEN** MUST 顯示需重新載入確認，保留原已存顯示，不重試覆寫

### Requirement: 條件附註須對應實際公式與當前設定

系統 MUST 提供可收合附註，呈現固定 BOLL(20,2)、共通價格／流動性／趨勢門檻，以及三階段的帶寬百分位、收縮、量縮、b 位置、近期壓縮、首次上破及不含今日的突破均量；數值 MUST 對應每日 criteria，分類優先為正式突破、準備突破、正在壓縮，不把準備突破寫成保證。

#### Scenario: 非預設參數
- **WHEN** 每日設定使用不同回看日數、放量倍數與最低價格
- **THEN** 附註 MUST 反映已載入參數，不固定顯示預設值；缺值仍為無法判定，不推論為未符合

### Requirement: 符合結果的階段名稱須醒目且保持可讀

結果卡片 MUST 獨立著色並加粗正在壓縮、準備突破、今日正式突破的文字，分別使用藍、金黃、紫色系。深色與淺色主題的一般文字對比 MUST 至少 4.5:1；MUST 保留階段名稱且不改變分類、操作或資料。無法判定與未符合 MUST NOT 套用符合階段色。

#### Scenario: 切換主題
- **WHEN** 使用者在深色、午夜或淺色主題查看三階段股票結果
- **THEN** 階段名稱 MUST 與股名分開著色，三種階段可辨識且足夠對比；結果內容與點選行為不變
