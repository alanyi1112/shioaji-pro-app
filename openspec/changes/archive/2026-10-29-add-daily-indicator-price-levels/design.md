## Context

主圖目前以所選時框的`bars`計算指標。`indicator-defs.ts`已有`reference-ma-pack`與`boll`，分別重用`referenceSma`及`bollinger`；預設布林參數為20期、2倍標準差。1m／5m／15m／60m初始歷史僅3／10／20／60個日曆日，不能拿該分鐘視窗直接計算120日均線。

`candle-chart.tsx`已有日線壓撐向分鐘圖投影的生命週期及價位renderer，但該reference使用已完成日K，另有歷史選棒與45日資料窗。這些資料／reference規則不適合本案的即時日線指標；只重用可拆出的渲染與標籤配置能力。`fetchKbars`已有30日分段、同請求single-flight及canonical驗證，1D初始歷史窗為240日曆日。

本案採用使用者已確認的時間基準：盤中納入今日未完成日K的最新合法close，所有分鐘圖使用同一個最新日線快照。文件建立階段不發行情請求、不修改程式或服務。

## Goals / Non-Goals

**目標：**

- 一個「日線關鍵價位」入口提供八項可選水平價位，在四種分鐘圖保持同源、同參數、同快照的數值一致。
- 不依賴使用者先開1D；功能啟用後可按既有圖表授權取得必要日線歷史，優先重用現有資料與在途請求。
- 保留forming、closed及各種資料不足／過期狀態，重用既有公式，避免分鐘資料冒充日線。
- 清楚標籤、跨疊加避碰與完整cleanup，保留使用者縮放、圖表選股及交易操作。

**非目標：**

- 不把這些價位改為分鐘均線曲線，不新增警示、策略、下單、監控名單或後端量比計算。
- 不新增MultiView功能、回測投影、歷史選棒／逐日階梯線；既有日線壓撐的reference與選棒規則不改。
- 不新建行情連線、SSE／subscription、背景排程、供應商或正式採集流程，不變更broker預算與限流Gate。

## Decisions

### 1. 獨立的單例投影指標

在既有canonical indicator store註冊`daily-indicator-levels`主圖疊加primitive，顯示名稱「日線關鍵價位」。未加入前不啟用、不額外載入；首次加入開啟八項，設定內可分別關閉及調整顏色／線寬／線型。均線週期固定5／10／20／60／120；布林週期與標準差倍數預設20／2，範圍沿用既有BOLL驗證（2–200期、0.5–5倍、步進0.5）。同一份功能設定只允許一個實例，防止重複載入與同名線。

設定獨立於普通`boll`與`reference-ma-pack`，因此不會修改現有分鐘指標。1D可開啟相同設定並核對來源狀態，但只在1m／5m／15m／60m畫水平投影。舊store未有此type時保持原設定；共用回測renderer及其他不具日線authority的consumer不渲染此primitive。

考慮過直接讓普通MA／BOLL強制跨時框；這會改變既有時框語意，也無法清楚區別日線價位與分鐘曲線，因此採獨立功能。

### 2. 每個商品一份日線authority，與圖表時框分離

規劃拆出日線資料協調器，商品key至少包含security type、region、exchange、code、target code；來源／交易時段／價格基準與資料generation參與快照身分，不能把不同還原基準或夜盤歸日規則混用。快照攜帶日K、交易日期、forming／closed／unknown、來源版本、coverage、來源as-of、接收時間及generation。商品支援沿用既有1D來源契約；時段或完成狀態無法證實時顯示unknown，不另以台股13:30套用所有商品。

資料流程：

```text
既有canonical日線／1m歷史與行情更新
                 │
        商品共用的1D資料協調器
        coverage／來源／generation驗證
                 │
     referenceSma ＋ bollinger純計算
                 │
        最新八項價位＋各項可用狀態
                 │
       1m／5m／15m／60m水平投影
```

優先訂閱既有相同商品的1D authority及合法快取；不足才透過同一既有圖表資料流程補足。目標日K數為已開啟MA的最大週期與已開啟任一布林軌所需期數的最大值，首次八項皆開啟時預設120日；全部關閉則沒有新增資料需求。按目標使用既有有界日線載入，初窗至多240日曆日，必要時向前擴至最多365個日曆日，30日chunk不重疊且單一循序，單次冷載最多13個chunk。這是額外上限，不是預先消耗額度的指示；快取已有coverage則不請求，較短週期取得足夠合法coverage後不再為已關閉的長週期載入，既有來源授權／預算／限流／逾時與取消守門優先。到界仍不足即逐項partial，不擴到既有1096日上限、不因換時框自動重試。

協調器按實際coverage合併相容需求，跨面板共用同商品在途請求；單一consumer離開不取消其他仍使用的consumer。最後一個consumer離開才中止本功能專屬請求與listener。保留有界LRU日線快照，最多沿用既有12個商品快取容量、每商品最多200個已完成日K加1個forming日K；不為八條線複製整年的raw 1m資料。新舊日期交界、重開頁面或來源刷新沿用既有圖表市場感知規則，不新增固定輪詢。

只將相同商品的合法既有tick／quote併入當前日K，不另subscribe。日線與分鐘圖共用canonical聚合／合法tick過濾，來源時間較舊、試撮、不相容generation或已取消回覆不得覆蓋快照。新交易日只在真實來源建立合法新日K後切換，不以系統換日或零量假棒補日數。歷史缺交易日依既有1D日期／品質契約辨識，不能跳過已知缺漏湊滿120。

考慮過從每個分鐘圖各抓一份長歷史，或要求先切1D。前者放大請求與記憶體，後者令功能無法直接使用，因此採商品共用authority。資料協調若不能在現有來源授權內安全完成，先回unavailable並保留精確缺口，不繞過Gate。

### 3. 使用既有日線公式與forming更新

輸入僅為同一快照的合法日K序列，使用既有`referenceSma`與`bollinger`，保留既有數值精度。日NMA是最後N個合法日K close平均；盤中包含今日forming close，所以日5MA包含前4個交易日與今日最新值。BOLL使用既有母體標準差（除以N），不另寫近似公式。參數及快照相同時，結果必須與1D指標輸出一致；比較不能混用不同tick時點。

每次有效行情只更新同一個forming日K並重算最新價位，不每tick新增一根日K。十字游標、橫向捲動與分鐘級別切換都不改參考日期。來源確認日K完成後才標closed；時間到不等於資料已完成。僅價格顯示使用既有formatter，不把實際MA／布林值吸附到商品tick size。

### 4. 水平線、標籤與縮放

八條價位使用獨立primitive，不以假candle、未來timestamp或普通分鐘LineSeries湊水平線。線在目前分鐘plot內水平延伸，代表「最新日線價位」，不是當年歷史已知價位；狀態列持續標示來源交易日。使用者捲到舊日資料時不改成該歷史日的指標，也不提供給回測renderer。

預設虛線、1px，均線顏色沿用參考均線組，布林沿用對應輸出色彩；右側標籤例如「日60MA 102.35」、「日BOLL上 105.20」。label配置抽成能與既有壓撐標籤共同避碰的介面，所有位移標籤以connector指回真實價位。值完全相同的本功能價位可合併標籤，例如「日20MA／日BOLL中軌」，但保留各output身分、開關與數值；僅格式化後相同或價格接近不可合併。不得合併或省略既有PP／三關／CDP的公式身分。

固定不加入新autoscale範圍，保持原K線大小與縱軸區間；不提供擴張選項，舊autoscale設定也不再生效。只畫目前可見價格範圍內的日線水平線及標籤，範圍外項目在label配置前即排除，仍可在數值清單查看，不把它夾到假的可見價格。任何切換皆不執行fitContent、不重設X軸、不改其他疊加的autoscale貢獻。

### 5. 資料狀態與設定保存

狀態列顯示「日線價位・日期・盤中暫估／已收盤／完成狀態未知」及來源更新時間。每項另有available、insufficient、stale或unavailable；分母概念不適用此指標，不能沿用量比unknown字樣代替日線不足。具有20日而不足120日時保留可算的5／10／20MA與BOLL，缺的60／120MA顯示「資料不足：需N日／已有M日」。

來源失敗時可保留同商品最後可證快照並明示過期時間與原因，以不同線型／降低醒目度表示暫存；無快照不畫線。市場感知freshness避免把正常休市的已完成日K誤標斷線。無關商品舊線立即清除；不得以0、目前分鐘MA或舊商品資料補缺。持久化只保存啟用、output開關、樣式、BOLL參數，不保存計算價位為永遠有效資料；儲存失敗保留目前記憶體設定並明示未保存。

## Risks / Trade-offs

- [長歷史API僅提供1m，冷載負擔較大] → 先重用1D、coverage及chunk去重，按需單一循序載入，有界365日／13 chunks；量測payload、載入耗時、記憶體，未測不宣稱零請求或立即完成。
- [缺日、停牌、新上市或來源不齊令長均線不可算] → 逐項availability與已知gap驗證，不補零、不擅取更早或不同基準來源。
- [forming日線價位與已完成日線被混淆] → 明示盤中暫估及as-of，關閉狀態須有來源依據，四個分鐘圖同快照核對。
- [日線BOLL參數與既有獨立BOLL不同] → 在日線價位設定與legend明示參數；只在相同參數／快照時要求相等，不默改其他實例。
- [八條新線與十五條壓撐線擁擠] → 逐條開關、同價身份保留、共用標籤避碰、窄面板測試及原價格視窗內繪製。
- [共用primitive或設定改動造成交易／回測回歸] → 隔離新type及輸入資料，檢查點價／拖單／警示與既有壓撐選棒，其他consumer不渲染即時日線投影。

## Migration Plan

1. 先完成離線純計算、來源協調與primitive測試，再接主圖與設定；保留工作區其他未完成變更。
2. 舊設定原樣沿用，不自動加入新type；使用者明確加入後才產生資料需求，schema驗證及同origin同步沿用canonical store。
3. 使用隔離瀏覽器fixture完成四種分鐘級別、forming／closed、缺值／失敗、避碰、縮放與快速換股驗證；型別、build及OpenSpec strict通過後，另依實作時授權進行本機載入與真實資料核對。
4. 真實驗證先重用已載入合法日線與行情；如需新增長歷史請求、重載或服務操作，先界定當次授權與有界需求，不能把本提案當作正式採集或服務操作授權。
5. 回退只移除／停用本功能接線與其設定，不清除舊指標、歷史資料、排程或收據；先清理primitive與共享consumer，再卸除新renderer。

## Open Questions

時間基準已由使用者確認，沒有阻擋文件完成的產品選項。實作第一步需驗證既有1D資料與quote更新可否抽成共用協調器，並量測冷載實際負擔；若必須新增供應商、擴大資料授權或改變既有日線聚合契約，應先更新設計及回報，不直接擴大範圍。
