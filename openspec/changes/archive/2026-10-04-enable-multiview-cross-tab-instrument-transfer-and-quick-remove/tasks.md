## 1. 釐清既有清單並建立頁籤成員身分

- [x] 1.1 以唯讀方式盤點系統／個人頁籤、`tab_id=''` 舊覆寫與清單 API 的有效成員規則；補齊可重現的系統對系統、系統對個人及個人對個人測試資料。
- [x] 1.2 建立以使用者、系統頁籤 ID、商品代號為唯一鍵的 per-system-tab 成員覆寫儲存；加入不刪舊列的相容遷移與無法判定歸屬時的診斷。
- [x] 1.3 將系統預設、舊覆寫、新系統頁籤覆寫及個人頁籤商品整合成按穩定頁籤 identity 查詢的有效清單，並驗證同一商品可同時存在於兩個系統頁籤。
- [x] 1.4 使既有管理畫面的新增、移除、排序與還原頁籤 API 共用有效成員解析；確認舊清單在刷新前後內容、順序及 metadata 不退化。

## 2. 實作安全的跨頁籤與快捷移除 API

- [x] 2.1 定義 transfer 與 quick-remove 的請求／回應契約；由 request principal 驗證使用者、來源及目的頁籤 identity、啟用狀態與確切來源成員，不接受只靠頁籤名稱或商品代號的廣泛刪除。
- [x] 2.2 以同一原子寫入實作 `move`：目的地新增或沿用並置頂、其餘商品順序收斂、來源指定成員移除或系統預設隱藏；失敗時兩邊皆不變。
- [x] 2.3 實作 `copy`：目的地置頂、來源不變；目的地已有商品時只沿用並置頂，保留既有備註與 metadata，不新增重複成員。
- [x] 2.4 實作只針對指定頁籤成員的 quick-remove；系統預設改為個人隱藏覆寫，個人頁籤只刪指定列，不影響其他頁籤。
- [x] 2.5 以伺服器最新有效清單計算排序並在成功後回讀；來源或頁籤狀態過期時回報衝突，並以失敗注入及並行請求測試原子性與冪等收斂。

## 3. 線圖卡片拖放與快捷操作

- [x] 3.1 延伸既有卡片 pointer drag 控制器，以商品標題手把辨識跨頁籤落點；維持圖內拖曳與原頁籤排序的原行為，單圖模式也可拖往其他頁籤。
- [x] 3.2 加入頁籤落點高亮、商品／目的頁籤／移動或複製文字預覽，並以放開當下的 Mac Option 狀態決定模式；Escape、pointercancel、blur、無效落點等都能完整取消與清理。
- [x] 3.3 在線圖右鍵及卡片標題 `⋯` 共用移動到、複製到與明確命名的移除操作；提供鍵盤及單指標可完成的目標選擇。
- [x] 3.4 加入移除確認對話框；若顯示代號與 canonical 清單商品不一致或目前商品非確切成員，停用快捷操作並說明原因。
- [x] 3.5 在未儲存排序完成前延後 mutation；pending 時避免重複操作，成功後只更新受影響頁籤及卡片，失敗／衝突時保留畫面並重新讀取，不自動切換頁籤。
