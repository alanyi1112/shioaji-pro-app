## Context

紅框內是每日策略狀態與停用鈕，三階段目前藏於手動條件編輯器。daily-profile 初始 GET 唯讀；PUT 採 expectedRevision，與瀏覽器草稿分離。現存 profile revision 1 啟用且三階段全選，本次不得為測試覆寫。

## Goals / Non-Goals

Goals：每日區預設收合、三個可鍵盤操作的 aria-pressed 按鈕、明確儲存、可收合條件說明與具體錯誤。

Non-Goals：不改公式、來源、排程、預算或交易流程；不自動寫入 profile，不重啟共用服務。

## Decisions

- 獨立每日元件持有階段草稿；已存 profile 初始化原階段，尚無 profile 時三階段預設全選。與手動條件編輯器的套用入口共存，但清楚標示其不同用途。
- 每日直接儲存以已存 criteria 為底，只更換 stages；初次設定使用停用所有舊條件的預設 v7 加啟用布林，避免不相關非法草稿阻擋每日操作。
- 空選擇顯示至少選一階段、禁止儲存，不暗中代表全選。停用只使用已存 criteria，不因未儲存空選擇而失效。
- 三階段說明依 criteria 數值產生，共通門檻、量縮／量增的含判定日差異、百分位排除判定日、首次突破與分類優先順序明列。只選某階段不改原分類優先序。
- 保留手動「套用至每日自動篩選」舊入口；每日 UI 提供「儲存每日策略」，兩者同用合法 PUT／CAS。
- 錯誤依 reason 分類，不將 403 同源拒絕、409 衝突或接口未就緒寫成籠統成功／失敗；不放寬跨來源保護。
- 結果卡片只將階段名稱獨立著色、加粗，股名與其他資料維持原樣。正在壓縮用藍色、準備突破用金黃色、今日正式突破用紫色；淺色主題使用同色系深色，確保一般文字對比至少 4.5:1。保留名稱，不以顏色取代語意；無法判定／未符合不套用三種符合色。

## Risks / Trade-offs

- 已有部分選擇與全選預設衝突 → 全選僅新設定，既有設定優先。
- 收合遮蔽失敗 → 結果訊息維持區塊外可見。
- 測試修改每日資料或訂閱 → browser fixture 驗證 PUT，真實頁面僅讀取與展開／切換後復原，不寫正式 profile。
- 同源代理可能是錯誤來源 → 先檢查現存 gateway；沒有根因證據不修改後端或安全限制。
