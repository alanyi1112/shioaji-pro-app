## MODIFIED Requirements

### Requirement: 商品資訊區與摘要必須依容器寬度響應排列
系統 MUST 依個別 K 線圖容器的 inline size 調整商品資訊區與行情摘要，不得只依整個瀏覽器 viewport 判斷。寬版 MUST 回收摘要 metric 內不必要的伸展空白，並在商品資訊區與摘要第一欄之間保留可辨識的間距。寬度不足時 MUST 優先保留完整內容，可增加列數、把摘要移到商品資訊區下方，或將商品資訊區降為單欄排列。商品資訊區不得覆蓋、推出或遮蔽行情摘要。

#### Scenario: 中等寬度圖表
- **WHEN** 圖表不足以讓商品資訊區與四欄摘要安全地左右並排，但仍可容納四欄摘要
- **THEN** 系統 MUST 將商品資訊區與摘要改為上下排列
- **AND** 摘要 MUST 保持四欄三列
- **AND** 商品資訊區 MUST 仍以兩欄兩列顯示代碼／最新價與名稱／漲跌資訊
- **AND** 商品資訊區右緣與摘要第一欄 MUST 保留明確間距，摘要欄位內的標題與數值 MUST 不因平均分散而產生不必要的大空白

#### Scenario: 極窄圖表或大字體
- **WHEN** 個別圖表寬度或目前字體倍率不足以完整容納四欄摘要或兩欄商品資訊區
- **THEN** 系統 MUST 將摘要降為較少欄數並增加列數，且可將商品資訊區降為單欄
- **AND** 所有標題、價格、數量與時間 MUST 完整可讀，不得被裁切或以省略號隱藏
- **AND** 商品代碼、最新價、漲跌與漲跌幅 MUST 不得覆蓋摘要或互相重疊
- **AND** 標題與對應數值 MUST NOT 被拆到不同列

#### Scenario: 同一工作區具有不同寬度圖表
- **WHEN** 同一 viewport 同時存在兩張以上不同寬度的 K 線圖
- **THEN** 每張 QuoteBoard MUST 依自己的容器寬度選擇商品資訊區與摘要排列
- **AND** 一張圖的 breakpoint MUST NOT 強迫其他圖採用相同排列

### Requirement: 商品資訊區必須保留主要行情資訊
商品資訊區 MUST 完整顯示商品代碼、名稱、最新價、漲跌、漲跌幅與既有漲跌停狀態，並以有界的響應式尺寸配置和摘要共享空間。寬版與中版商品資訊區 MUST 採兩欄兩列：第一列依序呈現商品代碼與最新價，第二列依序呈現商品名稱與同列的漲跌／漲跌幅；右側資訊 MUST 對齊，價格與百分比 MUST 不折行。

#### Scenario: 自選清單式商品資訊排列
- **WHEN** K 線圖容器可安全容納兩欄商品資訊區
- **THEN** 第一列 MUST 顯示商品代碼與最新價
- **AND** 第二列 MUST 顯示商品名稱與同一水平列的漲跌、漲跌幅
- **AND** 商品名稱 MUST 位於代碼下方，漲跌與漲跌幅 MUST 位於最新價下方並靠右對齊

#### Scenario: 字體倍率放大
- **WHEN** 使用者把介面字體倍率設定為 1.15 或 1.3
- **THEN** 商品代碼、名稱、最新價、漲跌及漲跌幅 MUST 保持可讀
- **AND** 商品資訊區與摘要 MUST NOT 相互覆蓋
- **AND** 價格、漲跌與漲跌幅 MUST 不得以折行或省略數字解決空間不足

#### Scenario: 標準看盤使用特大字級
- **WHEN** 標準看盤工作區約為 1499×821 CSS px、K 線面板約為 926px 寬，且字體倍率為 1.3
- **THEN** 商品代碼、名稱、最新價、漲跌與漲跌幅 MUST 完整顯示且不得互相遮蓋
- **AND** 四欄三列摘要的量、時間與賣量最右欄 MUST 完整留在面板內
- **AND** 系統 MUST 優先回收商品資訊區與摘要之間的閒置軌道及間距，不得以縮小文字、折行或省略數字解決

#### Scenario: 長指數價格
- **WHEN** 商品為 `IX0001` 或其他最新價包含較多整數位與小數位的指數
- **THEN** 最新價 MUST 位於商品代碼右側的第一列
- **AND** 漲跌與漲跌幅 MUST 位於最新價下方的第二列
- **AND** hero MUST NOT 將任一數字覆蓋到右側行情摘要

#### Scenario: 主視窗與獨立視窗
- **WHEN** 同一 K 線圖分別顯示於工作區主視窗或 popout
- **THEN** 系統 MUST 套用相同的容器響應與完整顯示規則

## ADDED Requirements

### Requirement: 摘要欄位標題與數值必須分別對齊
每個行情摘要 metric MUST 使用兩欄排列，標題固定位於該欄左側，對應數值固定位於該欄右側。同一摘要欄跨列的標題左界與數值右界 MUST 分別對齊；標題與數值 MUST 保持同一列，不得因內容長度而互相推移或拆列。

#### Scenario: 四欄摘要的欄內對齊
- **WHEN** 圖表容器可容納四欄三列摘要
- **THEN** 每一欄的三個標題 MUST 共用同一左邊界
- **AND** 每一欄的三個數值 MUST 共用同一右邊界
- **AND** 標題與數值之間 MUST 保留可讀的最小間距

#### Scenario: 窄版摘要的欄內對齊
- **WHEN** 摘要因容器寬度降為兩欄或一欄
- **THEN** 每個目前可見欄位仍 MUST 維持標題左對齊與數值右對齊
- **AND** 所有數值 MUST 完整顯示，不得以裁切、省略或水平溢位處理
