# main-chart-price-range Specification

## Purpose

定義主圖價格範圍工具的兩點選取、即時預覽、台股漲跌配色、量測結果、本機保存、生命週期隔離及完整 panel PNG 匯出行為。

## Requirements

### Requirement: 主圖繪圖工具必須提供價格範圍

系統 MUST 在每個 chart panel 的「主圖」繪圖工具提供「價格範圍」。啟動後第一次有效左鍵設定起點，第二次有效左鍵設定終點；此功能不得改變既有主圖指標、匯出圖片或副圖操作。

#### Scenario: 啟動後選取第一點
- **WHEN** 使用者選擇「價格範圍」並在主 K 線 plot 點選第一個有效價格位置
- **THEN** 系統 MUST 將該精確圖上價格與時間設定為起點
- **AND** MUST 進入等待終點的量測狀態

#### Scenario: 第一點後即時預覽
- **WHEN** 使用者已設定起點並將滑鼠移至另一個有效主圖位置但尚未點選
- **THEN** 系統 MUST 即時顯示起點至目前位置的價格範圍預覽
- **AND** 預覽 MUST NOT 寫入本機儲存，滑鼠離開主圖或按 Escape 後 MUST 消失

### Requirement: 價格範圍必須依錄影呈現區間與量測標籤

系統 MUST 以第一個左鍵錨點價格為起點、第二個左鍵錨點價格為終點，繪製由兩點時間與價格界定的半透明矩形、上下水平界線及中央垂直雙向箭頭。上漲區間 MUST 採紅色，下降區間 MUST 採綠色。上下水平界線 MUST 使用 1 CSS px，中央雙向箭頭與箭頭端點 MUST 維持 2 CSS px，避免界線遮住價位起點並保留量測方向辨識。上緣中央標籤 MUST 顯示含正負號語意的絕對價差與百分比；百分比 MUST 依 `((終點價格 - 起點價格) / 起點價格) × 100` 計算，且可取得商品 tick size 時 MUST 顯示最小跳動格數。起點價格為零、非有限值或座標轉換失敗時 MUST 拒絕量測。

#### Scenario: 量測上漲
- **WHEN** 使用者選取高於第一錨點的有效第二錨點
- **THEN** 圖上 MUST 顯示正的價格差與正的百分比
- **AND** 結果 MUST 使用商品既有價格 formatter
- **AND** 矩形、界線與雙向箭頭 MUST 使用上漲樣式

#### Scenario: 量測下跌
- **WHEN** 使用者選取低於第一錨點的有效第二錨點
- **THEN** 圖上 MUST 顯示負的價格差與負的百分比
- **AND** 百分比 MUST 以第一錨點價格為分母
- **AND** 矩形、界線與雙向箭頭 MUST 使用下跌樣式

#### Scenario: 台股漲跌配色與界線層級
- **WHEN** 主圖同時顯示上漲與下降價格範圍
- **THEN** 上漲區間 MUST 使用紅色，下降區間 MUST 使用綠色
- **AND** 上下水平界線 MUST 為 1 CSS px，中央雙向箭頭與箭頭端點 MUST 為 2 CSS px
- **AND** 起點價位的水平位置 MUST 保持可辨識

#### Scenario: 無效起點
- **WHEN** 起點位置無法換算出有限且非零的圖上價格
- **THEN** 系統 MUST 不建立價格範圍註記
- **AND** MUST 顯示可理解的失敗狀態而不影響 K 線操作

### Requirement: 價格範圍必須與主圖生命週期一致

完成的價格範圍 MUST 依 canonical symbol 與 interval 保存於瀏覽器本機，暫態選取不得保存。覆蓋層 MUST 隨縮放、平移、resize、切換商品或週期正確重繪或隔離，且不攔截一般圖表手勢。完整 panel PNG MUST 包含目前可見的價格範圍矩形、雙向箭頭與結果文字。舊版 `distance` 完成資料 MUST 可遷移為 `priceRange`，且不得影響同一身份保存的費波那契註記。

#### Scenario: 取消或清除量測
- **WHEN** 使用者按 Escape 取消未完成量測或使用清除操作移除完成量測
- **THEN** 系統 MUST 移除相應暫態或完成覆蓋層與本機資料
- **AND** 費波那契、固定區間成交量剖面及其他主圖功能 MUST 維持不變

#### Scenario: 切換身份與匯出
- **WHEN** 使用者切換至另一商品／週期後再匯出目前 panel
- **THEN** 系統 MUST 不顯示先前身份的價格範圍
- **AND** PNG MUST 只包含目前身份可見且已完成的價格範圍註記
