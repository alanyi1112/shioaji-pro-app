## ADDED Requirements

### Requirement: 估算融資成本的逐日計算

系統 MUST 以同一商品逐日融資餘額、融資買進張數與日 K 收盤價，使用移動平均成本法計算「估算融資成本」；新增融資部位 MUST 以當日收盤價加入成本，融資賣出與現金償還 MUST 以原平均成本減少部位而不重估剩餘成本。第一筆可計算日期 MUST 以該日收盤價建立種子並標示 `seeded`，結果 MUST 附帶 `formulaVersion`、資料日期及估算註記，不得稱為投資人實際融資買進均價。

#### Scenario: 融資餘額增加
- **WHEN** 前一日有合法估算成本與融資餘額，且當日融資買進後仍有未償餘額
- **THEN** 系統 MUST 以「前一日未償部位成本加上當日融資買進張數乘當日收盤價」除以買進後部位計算新平均成本
- **AND** 當日融資賣出與現金償還 MUST 以該平均成本扣除，不得改變剩餘部位的每股估算成本

#### Scenario: 第一筆或歸零後重新建立部位
- **WHEN** 查詢範圍第一筆合法資料已有融資餘額，或前一日融資餘額為零而當日重新出現餘額
- **THEN** 系統 MUST 以當日收盤價作為該段部位的估算成本種子
- **AND** response MUST 將該點標示為 `seeded`，UI MUST 可揭露其不是完整歷史成本

#### Scenario: 流量與餘額無法核對
- **WHEN** 融資買進、賣出、現金償還與前後餘額的單位不一致、缺漏或超出允許的官方調整差異
- **THEN** 系統 MUST 將該日估算成本標示為 `null` 或 `partial`
- **AND** MUST NOT 以零值、未揭露的固定價格或任意回推結果接續成本序列

### Requirement: 估算融資維持率的逐日計算

系統 MUST 只在同日具有合法收盤價、估算融資成本及可追溯的融資成數時，依 `收盤價 ÷（估算融資成本 × 融資成數）× 100%` 計算「估算融資維持率」。融資成數 MUST 來自可驗證的商品或市場規則資料並附來源日期；缺少成數時 MUST 回傳 `null`，不得自行假設 60% 或其他固定值。

#### Scenario: 所有輸入皆合法
- **WHEN** 某交易日具有收盤價、估算融資成本與適用融資成數
- **THEN** API MUST 回傳該日估算融資維持率、融資餘額變化張數、輸入值與 `formulaVersion`
- **AND** UI MUST 以百分比顯示維持率並保留「估算」名稱

#### Scenario: 融資成數或估算成本缺漏
- **WHEN** 某日缺少可驗證融資成數、估算成本或合法收盤價
- **THEN** 該日估算融資維持率 MUST 為 `null` 並提供可辨識原因
- **AND** MUST NOT 沿用前值、內插或套用未揭露的市場常數

### Requirement: 主圖估算融資成本線

eligible 台股普通股與 ETF 主圖 MUST 在主圖線選單提供可獨立開關的「估算融資成本」；線條 MUST 與 K 線共用價格尺度及交易日時間軸，預設關閉，偏好 MUST 依 `tabId + canonical symbol` 保存。非台股、無融資資格或資料不完整的商品 MUST 顯示不適用或缺值，不得畫零線。

#### Scenario: 開啟估算融資成本
- **WHEN** 使用者在 eligible 台股 panel 勾選「估算融資成本」
- **THEN** 主圖 MUST 顯示同日期估算成本折線並與 candles 保持小於等於 1 CSS px 的日期對齊
- **AND** 游標讀值、圖例或說明 MUST 顯示「估算」及 seeded／partial 狀態

#### Scenario: 切換商品或關閉線條
- **WHEN** 使用者切換商品、頁籤、圖數或取消勾選
- **THEN** controller MUST 清除舊商品 series、事件 listener 與 pending response
- **AND** 慢回應 MUST NOT 污染新商品，重新返回時 MUST 恢復該商品保存的偏好

### Requirement: 估算融資維持率副圖

系統 MUST 在「融資券」群組提供可獨立選取的「估算融資維持率」折線 pane；標題列 MUST 依共同游標日期顯示估算融資維持率與融資餘額增減張數，並沿用既有籌碼副圖的方式 A／B、共用時間軸、右鍵線圖項目、詳細資料、截圖、排序與 lifecycle 行為。該 pane MUST 與融資及融券共用同一份相容資料 response，不得為相同 `symbol + range` 重複呼叫上游。

#### Scenario: 顯示估算融資維持率
- **WHEN** 使用者在方式 B 勾選「估算融資維持率」且游標日期有合法結果
- **THEN** pane MUST 以折線顯示百分比
- **AND** 標題列 MUST 顯示同日估算融資維持率及帶正負號的融資增減張，增加為紅色、減少為綠色、持平為中性色

#### Scenario: 指向缺值日期
- **WHEN** 共用游標指向無合法估算結果的交易日
- **THEN** 標題列 MUST 顯示「無資料」與原因，折線 MUST 保留 gap
- **AND** MUST NOT 顯示最近前值為指向日期的結果
