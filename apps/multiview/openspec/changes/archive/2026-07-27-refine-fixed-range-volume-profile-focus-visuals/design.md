## Context

固定範圍 VP 目前以數個同層 DOM 元素組成：範圍命中區、成交量柱、VAH／POC／VAL 水平線與價格標籤，以及只在選取範圍出現的左右拖曳控制線。現行渲染只替選取範圍建立價格標籤，範圍命中區則以 inline border 與 box-shadow 畫出縱向邊界；失焦狀態僅以整體透明度降低，因此仍留下縱線，卻失去關鍵價格資訊。

## Goals / Non-Goals

**Goals:**

- 聚焦與失焦範圍都建立 VAH／POC／VAL 水平線及價格標籤，並以透明度區分狀態。
- 失焦範圍完全移除可見的左右縱向邊界，同時保留範圍命中區以便重新選取。
- 聚焦範圍只用 2 CSS px 拖曳控制線標示左右界，避免額外陰影擴大視覺粗細。
- 降低柱狀圖、水平線、標籤與範圍底色的不透明度，讓下方 K 棒仍可讀。

**Non-Goals:**

- 不變更 VP 的 bucket、VAH、POC、VAL 計算。
- 不變更範圍拖曳、重新選取、刪除或持久化資料格式。
- 不調整一般 Volume Profile 或其他主圖繪圖工具。

## Decisions

### 1. 價格標籤一律渲染，再用狀態 class 區分

`appendFixedProfileLevel` 不再於失焦時提前返回；水平線與價格標籤都依 `isSelected` 加上 `is-muted`。這能保證切換焦點只改變視覺狀態，不會改變資訊是否存在，也方便 DOM 契約與瀏覽器驗收。

替代方案是失焦時另建摘要標籤，但會產生兩套定位與碰撞規則，且容易與實際水平線脫鉤，因此不採用。

### 2. 範圍命中區不負責畫縱線

移除 `.fixed-profile-range` 的左右 border 與選取狀態 inline box-shadow。失焦命中區維持透明；聚焦命中區只保留 `rgba(250, 204, 21, 0.025)` 的淡底色。左右界只由選取範圍的拖曳控制線顯示，因此失焦後自然不殘留縱線。

替代方案是用透明 border 保留盒模型寬度，但現有絕對定位不依賴 border，直接移除可避免瀏覽器抗鋸齒留下細線。

### 3. 聚焦縱向控制線固定為 2 CSS px

拖曳控制線採 `width: 2px`、`margin-left: -1px`，移除外擴 box-shadow 與左右附加 border。這與一般 VAH／VAL 水平線的 2 CSS px 相同；POC 仍保留 3 CSS px 的既有強調層級。

### 4. 使用分層透明度而非整組 opacity

- 一般柱段 `0.18`、Value Area 柱段 `0.46`、POC 柱段 `0.62`；失焦 bucket 再乘上 `0.62`。
- 一般水平線色彩 alpha `0.72`、POC `0.82`；失焦線使用 `opacity: 0.58`。
- 價格標籤背景 alpha 降至 `0.82`，失焦標籤使用 `opacity: 0.68`。
- 聚焦範圍底色 alpha 為 `0.025`，失焦範圍底色完全透明。

分層設定可保留 POC 與 Value Area 的相對層級，同時讓 K 棒透出；若在父層套用單一 opacity，文字、線條和互動命中區會一起變得過淡。

## Risks / Trade-offs

- [多個範圍價位接近時，失焦標籤可能重疊] → 保留每個範圍名稱前綴與既有單一範圍內避碰規則；本次不擴張為跨範圍標籤排版。
- [降低透明度後在低對比螢幕上可能偏淡] → 保留各層級的色相、線型與 POC 較高權重，並以瀏覽器實際畫面驗收。
- [移除範圍 border 後重新選取區域不明顯] → 範圍命中區與柱狀圖仍可點選，失焦的三條水平線及標籤也維持可見並可點回焦點。

## Migration Plan

1. 更新前端渲染與 CSS 狀態。
2. 更新渲染契約測試與靜態資產 cache key。
3. 執行單元測試與 OpenSpec strict validation。
4. 在瀏覽器建立至少兩個固定範圍 VP，逐項檢查聚焦與失焦 computed style。

若需回復，只需還原本次前端、測試與 cache key 變更；資料格式不需 migration。
