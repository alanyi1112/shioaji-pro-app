## ADDED Requirements

### Requirement: 主圖必須提供費波那契繪圖工具入口

系統 MUST 在每個 chart panel 的「主圖」選單提供獨立的「繪圖工具」入口，至少可啟動「費波那契回撤」與「費波那契拓展」，並清楚顯示目前等待的錨點數。工具入口不得改變均線、布林、成交量、FVG、Volume Profile、本益比河流圖或副圖的既有選取狀態。

#### Scenario: 啟動回撤工具
- **WHEN** 使用者在主圖選單選擇「費波那契回撤」
- **THEN** 系統 MUST 進入等待兩個錨點的回撤選取狀態
- **AND** 主 K 線、十字線與既有主圖指標 MUST 維持可見

#### Scenario: 啟動拓展工具
- **WHEN** 使用者在主圖選單選擇「費波那契拓展」
- **THEN** 系統 MUST 進入等待三個錨點的拓展選取狀態
- **AND** UI MUST 說明目前尚需選取的錨點數

### Requirement: 費波那契回撤必須以兩個波段錨點計算並標示價格

系統 MUST 以使用者依序選取的 A（波段起點）與 B（波段終點）建立回撤，並繪製 0、0.236、0.382、0.5、0.618、0.786、1 水準。每條水準線的價格 MUST 依 `B - r × (B - A)` 計算，且每一條線 MUST 以「比率（價格）」格式同時顯示小數比率與使用該商品既有價格格式化規則計算的對應價格。

#### Scenario: 上漲波段回撤
- **WHEN** 使用者先選較低的 A 價格再選較高的 B 價格並完成回撤
- **THEN** 系統 MUST 以指定公式產生全部七條回撤線
- **AND** 每條線的可見標籤 MUST 同時包含百分比與對應價格

#### Scenario: 下跌波段回撤
- **WHEN** 使用者先選較高的 A 價格再選較低的 B 價格並完成回撤
- **THEN** 系統 MUST 依同一公式正確反映下跌波段方向
- **AND** 系統 MUST NOT 假設 A 必須低於 B 或省略任何水準價格

### Requirement: 費波那契拓展必須以三個錨點計算並標示價格

系統 MUST 以使用者依序選取的 A、B、C 建立拓展，並在每次有效點選後立即以細線透明空心圓顯示已選取位置；A、B、C 只作為計算順序語意，不得繪製在圓內。系統 MUST 繪製 0.618、0.786、1、1.272、1.414、1.618、2 水準。每條水準線的價格 MUST 依 `C + r × (B - A)` 計算，且每一條線 MUST 以「比率（價格）」格式同時顯示小數比率與使用該商品既有價格格式化規則計算的對應價格。

#### Scenario: 完成三點拓展
- **WHEN** 使用者完成 A、B、C 三個有效錨點
- **THEN** 系統 MUST 繪製全部七條拓展水準線與各自的比率、對應價格標籤
- **AND** 拓展價格 MUST 由 A 至 B 的波段差與 C 共同決定
- **AND** 圖上 MUST 保留三個透明空心圓錨點及 A→B→C 計算順序的波段導引線，但圓內不得顯示字元

#### Scenario: 錨點或價格格式更新
- **WHEN** 註記因商品／週期重繪、錨點調整或價格 formatter 更新而重新呈現
- **THEN** 系統 MUST 重新計算每一條水準價格與標籤
- **AND** MUST NOT 沿用已過期的格式化價格文字

#### Scenario: 三點選取進度
- **WHEN** 使用者已選取 A 或已選取 A、B，但尚未選取完整三點
- **THEN** 系統 MUST 立即顯示已選錨點的透明空心圓
- **AND** UI MUST 同時說明尚需選取的錨點數，且不得預先顯示尚未選取的錨點

#### Scenario: 滑鼠移動預覽下一個錨點
- **WHEN** 使用者已啟動費波那契工具，並將滑鼠移到下一個有效主圖位置但尚未點選
- **THEN** 系統 MUST 以低透明度空心圓及暫態導引線預覽下一個錨點，圓內不得顯示 A、B 或 C
- **AND** 回撤已有 A 時 MUST 即時預覽 A 至 B 的水準，拓展已有 A、B 時 MUST 即時預覽 B 至 C 的拓展水準
- **AND** 暫態預覽 MUST NOT 寫入本機儲存，滑鼠離開主圖或按 Escape 後 MUST 消失

### Requirement: 費波那契必須以細實線、分區色帶與左側標籤呈現

費波那契水準線 MUST 以專屬範圍、細實線、相鄰半透明色帶與左側標籤呈現：回撤水平線由 A、B 較左的 X 座標開始，拓展水平線由 B、C 較左的 X 座標開始，兩者均向右延伸至價格縱軸前的 plot 安全邊界。水平線 MUST 使用約 1.5 至 2 CSS px 的實線，不得使用既有粗 halo 或水平虛線；波段導引線 MUST 維持較細虛線。標籤 MUST 優先位於水平線起點左側，採「比率（價格）」格式並沿用各水準色；空間不足時可移入水平線內側。辨識方式不得只依靠顏色，並且 MUST 與 K 線、均線、價格網格、本益比河流圖及價格範圍保持可辨識差異。

#### Scenario: 回撤與拓展線條辨識
- **WHEN** 費波那契與既有主圖指標同時顯示
- **THEN** 使用者 MUST 可由局部延伸範圍、細實線、相鄰色帶、左側文字及虛線波段導引辨認費波那契水準
- **AND** 水平實線與波段虛線 MUST 維持不同角色，不得以粗 halo 遮住水準價位

#### Scenario: 水平線延伸至價格縱軸附近
- **WHEN** 使用者預覽或完成回撤與拓展
- **THEN** 回撤水準 MUST 由 A、B 較左的 X 座標延伸到價格縱軸前，拓展水準 MUST 由 B、C 較左的 X 座標延伸到價格縱軸前
- **AND** 水準線與色帶 MUST 停在 plot 安全邊界，不得蓋住右側價格刻度或標籤

#### Scenario: 深色與密集主圖
- **WHEN** 主圖同時具有多根 K 線、均線、河流線或價格網格
- **THEN** 三個透明空心圓錨點 MUST 以約 1.25 CSS px 的細框準確置中於所選時間／價格座標，圓內 K 棒與價位 MUST 保持可見
- **AND** 錨點圓內 MUST NOT 顯示 A／B／C 或其他字元，也不得以填色遮住 K 棒
- **AND** 新樣式 MUST 維持 `pointer-events: none`，不得攔截縮放、平移、十字線或右鍵操作

#### Scenario: 拓展全部水準位於價格軸內
- **WHEN** 0.786、1、1.272、1.414、1.618 或 2 拓展價超出目前 K 線高低範圍
- **THEN** 主圖價格軸 MUST 納入目前拓展的最低與最高水準，使全部七條水準與標籤可見
- **AND** 清除拓展、取消預覽或切換商品／週期後 MUST 清除相應價格軸輔助範圍

### Requirement: 費波那契註記必須安全重繪、保存及匯出

完成的費波那契註記 MUST 依 canonical symbol 與 interval 保存於瀏覽器本機；暫態選點不得保存。覆蓋層 MUST 隨縮放、平移、resize 與圖表重建重新對齊，保持不攔截 K 線手勢；每個價格標籤 MUST 位於 panel 可見範圍，並在可用空間不足時安全移入水平線內側，而實際水準線價格位置不得改寫。完整 panel PNG MUST 包含目前可見的費波那契線、色帶與標籤。

#### Scenario: 切換商品或週期
- **WHEN** 使用者由某個商品或週期切換至另一身份
- **THEN** 系統 MUST 只載入新身份保存的完成費波那契註記
- **AND** 舊身份的暫態選點與畫面內容 MUST NOT 殘留

#### Scenario: 損毀本機註記
- **WHEN** 瀏覽器本機保存的費波那契資料無法解析、版本不相容或含非有限錨點
- **THEN** 系統 MUST 安全忽略或移除該筆資料
- **AND** 主圖 MUST 繼續載入且不得發出 API 或 D1 寫入

#### Scenario: 匯出含費波那契的完整 panel
- **WHEN** 使用者在費波那契註記可見時執行「儲存此商品所有線圖為圖片」
- **THEN** PNG MUST 包含與畫面相同的水準線及百分比、價格標籤
- **AND** 匯出不得遺失既有 K 線、主圖指標或副圖

### Requirement: 費波那契工具必須可取消與清除

系統 MUST 支援使用 Escape 取消未完成的費波那契選點，並提供清除已完成費波那契註記的明確操作。取消或清除後 MUST 移除對應暫態覆蓋層、listener 與本機保存資料，且不得影響其他主圖指標或價格範圍註記。

#### Scenario: Escape 取消未完成選點
- **WHEN** 使用者在尚未選滿回撤或拓展錨點時按 Escape
- **THEN** 系統 MUST 退出該工具的選取狀態並移除暫態提示
- **AND** MUST NOT 建立或保存不完整註記

#### Scenario: 清除已完成註記
- **WHEN** 使用者選擇清除費波那契註記
- **THEN** 系統 MUST 移除目前身份的費波那契覆蓋層與本機保存資料
- **AND** 價格範圍與既有固定區間成交量剖面 MUST 維持不變
