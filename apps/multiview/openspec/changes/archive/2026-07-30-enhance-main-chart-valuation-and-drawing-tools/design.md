## Context

目前河流圖由 Worker 計算五個本益比百分位，前端以獨立 SVG 覆蓋層呈現；主圖已有技術指標選單、固定區間成交量剖面兩點選取、右鍵選單與完整 panel PNG 匯出。這些能力尚未提供一般繪圖工具的共用狀態與覆蓋層管理，右鍵事件也只會解析指向日期，未保留圖上價格座標。

本次變更必須保持 Codex Sites／Worker 相容性、既有 K 線操作與河流資料來源不變，且不得將使用者繪圖資料送往 API、D1 或第三方服務。需求關係人是需要在主圖做估值閱讀、技術分析與價格量測的終端使用者。

費波那契互動以使用者提供的[教學影片](https://youtu.be/h_0mhbkGDQE)為參考：20:44 起示範回撤 A／B 設點與局部水平範圍，24:10 起示範水平延伸，24:50 起示範拓展 A／B／C 三點及即時水準。三點數學語意另與 TradingView 官方的 [Trend-Based Fib Extension](https://www.tradingview.com/support/solutions/43000518137-trend-based-fib-extension-drawing-tool/) 定義核對：前兩點定義波段，第三點定義回撤位置。

## Goals / Non-Goals

**Goals:**

- 將河流圖的機率切分提升為七條百分位線與六個區間，同時維持資料計算、讀值與 SVG 圖層的一致性。
- 提供可由「繪圖工具」啟動的費波那契回撤與拓展，讓每一個水準線同時顯示百分比與依錨點計算、依商品價格格式化的價格。
- 提供由主圖繪圖工具啟動的價格範圍，準確量測兩個使用者指定圖上價格點的價差、漲跌幅與最小跳動格數。
- 提供主 K 線數值讀值的左上角與浮動視窗模式，預設以左上角持續顯示最新或游標指向資料。
- 讓繪圖、量測、重繪、商品／週期切換、清除與 PNG 匯出有一致且可測試的生命週期。

**Non-Goals:**

- 不將百分位、費波那契或價格範圍解讀為買賣訊號、目標價或投資建議。
- 不變更河流圖的資料來源、五年／最小樣本邊界、D1 schema 或排程。
- 不新增帳號同步、跨裝置同步、伺服器端繪圖保存或外部繪圖函式庫。
- 不調整報價、商品標題、K 線價格軸或副圖的字級。

## Decisions

### 1. 以七個固定百分位與相鄰區間呈現河流圖

Worker SHALL 以 P5、P20、P35、P50、P65、P80、P95 計算各 session 的本益比倍率，前端依相鄰兩線繪製六個機率帶。色彩採低估端冷色、中央中性色、高估端暖色，並以文字明確標示這是歷史百分位區間而非預測。此做法保留現有 payload 結構與 SVG 圖層架構，只擴充固定鍵值、色票與 readout。

考慮過改為使用者可設定百分位；但這會增加設定持久化、無效輸入與測試組合，且未被需求要求，因此本次採固定七線。

### 2. 使用共用的主圖註記狀態與 SVG 覆蓋層

費波那契與價格範圍 SHALL 使用獨立於河流圖的主圖註記管理器：狀態含工具種類、目前選點階段、錨點、完成註記及其商品／週期身份。覆蓋層跟隨 chart pane 的尺寸、time scale 與 price scale 重繪，並與既有固定區間成交量剖面共存，不攔截正常拖曳、縮放與十字線操作。

以 SVG 作為註記層，而非把線段畫進 canvas 或另加圖表 series，原因是 SVG 可在右側保留價格標籤、可提供語意標籤，也能直接被既有完整 panel PNG 匯出流程帶入。實作時須以目前 chart API 可用的時間／價格座標轉換方法取得錨點與線端位置；不能假定特定 library 私有 API 存在。

### 3. 費波那契採固定、可重現的數學水準與價格標籤

回撤由兩個錨點 A（波段起點）與 B（波段終點）組成，水準為 0%、23.6%、38.2%、50%、61.8%、78.6%、100%，每條線的價格為 `B - r × (B - A)`。此式會依 A、B 的方向自動對應上漲或下跌波段。

拓展由 A、B、C 三個錨點組成，水準為 0.618、0.786、1、1.272、1.414、1.618、2，每條線的價格為 `C + r × (B - A)`。每條回撤或拓展線都使用商品 tick size／既有價格 formatter 顯示「比率（價格）」，價格於錨點移動、商品或週期重繪時重新計算。標籤優先置於水平線起點左側並與真實價格座標對齊；起點左側空間不足時才移入色帶內，且不得被價格軸裁切。

考慮過只顯示百分比或只在滑鼠提示中顯示價格；這會無法滿足每個波段點直接閱讀對應價格的需求，因此不採用。

### 3.1 以透明空心錨點、細實線與半透明色帶建立視覺層級

費波那契選點 SHALL 在每次有效點選後立即顯示對應的圓形錨點；滑鼠移動到下一個有效圖上位置時，以較低透明度空心圓預覽下一個錨點及尚未固定的波段導引線。回撤在已有第一點與預覽第二點時即時計算水準；拓展在已有第一、第二點與預覽第三點時即時計算水準。完成後仍保留錨點與三點波段導引線，讓使用者能辨認計算來源。圓形錨點採較小半徑、約 1.25 CSS px 的淺色外框、`fill: none`，不得繪製 A／B／C 字元，也不得把圓心移離實際時間／價格座標，讓圓內 K 棒與精確選點價位保持可見。

費波那契水準線 SHALL 由相關波段錨點的較左 X 座標開始，向右延伸至扣除價格縱軸寬度後的 plot 安全邊界：回撤以第一、第二點決定左起點；拓展以第二、第三點決定左起點。各水準採約 1.5 至 2 CSS px 的彩色實線，相鄰水準間以低透明度色帶建立層級；標籤使用相同水準色，並以文字描邊維持深色主圖可讀性。波段導引線維持較細虛線，與水平實線形成形狀差異。此設計同時以延伸範圍、色帶、實／虛線角色、文字與空心錨點區分 K 線、均線、價格網格、本益比河流及價格範圍。

### 3.2 以隱形價格邊界 series 納入拓展水準

SVG 註記本身不參與 Lightweight Charts 的價格軸自動範圍，這會使超出目前 K 線高低點的拓展水準雖已計算卻落在 plot 外。主圖 SHALL 以不顯示線、價格線、最後值或十字線標記的輔助 series，把目前完成或預覽中的拓展最低與最高水準納入同一右側價格軸；沒有拓展時清空輔助資料。輔助 series 只處理顯示範圍，不寫入本機註記，也不出現在圖例或匯出文字中。

### 4. 價格範圍採繪圖工具的兩點式互動

主圖「繪圖工具」提供「價格範圍」。啟動後第一次有效左鍵固定起點，滑鼠移動時即時預覽至目前位置的半透明矩形；第二次有效左鍵固定終點。矩形上下界由兩點價格決定、左右界由兩點時間決定，中央繪製垂直雙向箭頭，上緣中央顯示絕對價差、`((終點 - 起點) / 起點) × 100` 的百分比，以及可取得商品 tick size 時的最小跳動格數。配色依台股慣例採紅漲綠跌，且不只靠顏色傳達正負值。為避免遮住價位起點，上下水平界線採 1 CSS px，中央雙向箭頭與箭頭端點維持 2 CSS px，使區間邊界與量測方向形成清楚的視覺層級。

工具以 Escape 取消未完成選取並移除預覽，提供明確的清除入口。以直接座標取樣而非指向 K 線 close 價，才能符合「價格範圍」量測任意圖上價格的目的。舊版 `distance` 本機資料在讀取時遷移為 `priceRange`，避免既有完成量測消失。

### 5. 本機持久化以商品與週期作為資料邊界

完成的費波那契與價格範圍註記 SHALL 寫入既有瀏覽器本機儲存慣例，資料鍵至少包含商品與時間週期。切換身份時，介面只載入相同身份的完成註記；無法解析、版本不相容或價格資料失效的儲存內容 SHALL fail-safe 清除或忽略，不得阻礙主圖載入。暫態選點不寫入儲存。

考慮過 D1 保存以跨裝置同步；這會引入帳號、資料治理與 API 成本，與本次範圍不符，因此不採用。

### 6. 以佈局密度限定交易品種選單字級

主圖「交易品種」選單在單一／雙圖配置使用 13px，在三圖以上密集配置使用 12px；既有控制項高度、鍵盤操作、可存取名稱與選項完整文字維持不變。長商品名稱以可預期的單行截斷處理，避免推擠價格資訊。這只調整該選單，避免全域 `select` 樣式意外影響其他控制項。

### 7. 主 K 線 readout 提供固定與浮動兩種顯示模式

每個主圖選單 SHALL 提供「數值顯示」選擇器，可選「圖區左上角」或「浮動視窗」。預設為左上角，並以同一瀏覽器本機偏好同步所有 chart panel。左上角模式在滑鼠未指向有效 K 線時顯示最新一筆 OHLC 與已啟用主圖指標數值；游標指向有效日期時在原位置更新為該日數值。浮動視窗沿用既有跟隨游標、依左右空間避讓及離開圖區後隱藏的行為。

只切換同一個 main readout 容器的定位與可見生命週期，不建立兩份數值 DOM，避免 OHLC、均線、成交量、布林、FVG、Volume Profile、本益比河流與估算融資成本出現不同步。副圖標題列與籌碼 pane 的 inline readout 不受此模式影響。偏好只保存模式代碼，不含商品資料、帳號或秘密值。

## Risks / Trade-offs

- [圖表座標轉換在 resize、捲動或資料空洞時回傳空值] → 所有錨點與重繪均驗證有限時間／價格；無效時略過繪製並保留可安全清除的資料。
- [費波那契標籤靠近圖左緣時空間不足] → 優先置於起點左側，估算文字寬度不足時移到水平線內側，並以文字描邊維持可讀性。
- [新覆蓋層干擾既有圖表手勢或固定區間成交量剖面] → 以 pointer-events 分層，只有已武裝工具的必要事件會處理；補齊共存與取消流程的瀏覽器測試。
- [本機儲存舊版或損毀資料造成載入錯誤] → 使用版本化、可驗證資料形狀與 fail-safe 忽略／移除策略。
- [七線河流增加視覺雜訊] → 使用低飽和機率帶、清楚圖例與固定中央 P50，並以測試確保讀值和線條數量一致。
- [費波那契線與既有線條混淆] → 以延伸到價格軸前的細彩色實線、相鄰半透明色帶、虛線波段導引與透明空心錨點共同區分，且保持 `pointer-events: none`。
- [錨點標記遮住所選 K 棒與價位] → 移除填色及 A／B／C 字元，縮小半徑並採 1.25px 外框；圓心維持原始座標，不再為邊界裁切而平移。
- [拓展高低水準落在目前價格軸外] → 以不顯示內容的輔助 series 納入拓展最低／最高價，完成與預覽狀態都更新，清除或切換身份時同步清空。
- [左上角 readout 遮住密集 K 線或價格軸] → 限制在扣除右側價格軸的 plot 寬度，維持低干擾文字陰影與 `pointer-events: none`；使用者仍可切回浮動視窗。

## Migration Plan

1. 先擴充 Worker 百分位常數、回應測試與前端河流覆蓋層，讓舊五線 payload 可被安全忽略或明確重新載入。
2. 加入註記管理器、費波那契工具、價格範圍與專屬 CSS，不移除既有固定區間成交量剖面。
3. 為交易品種選單加入範圍限縮的密度字級規則。
4. 執行單元、渲染 HTML、互動瀏覽器、PNG、已登入與匿名 API 驗收後，依既有 Sites 發布流程部署。
5. 若發布後發生圖表互動或河流讀值迴歸，回退 Sites 至前一已驗證版本；本機註記可保留，因其不會改寫後端資料。
