# 共用交易日曆與特殊休市（本機）

## 使用方式

1. 從上方「交易日曆」選單開啟；盤中監控名單頁也保留同一入口。按「讀取特殊休市設定」。
2. 選擇台北日期及「上市＋上櫃／僅上市／僅上櫃」，填寫原因，例如「颱風臨時休市」。適用市場全日，非個別商品暫停交易。
3. 核對日期、原因及市場全日範圍，勾選確認，再按「確認新增特殊休市日」。無須公鑰、私鑰、人工簽章或官方收據；系統不代填實際休市日期。
4. 保存失敗或版本衝突時，重新讀取後核對，不能假設前次已保存或重複按送出。畫面只確認設定保存，不宣稱當日完整驗收。

可補登至 2000-01-01，未來最多 366 日。更正採「選擇撤銷」→填新原因→再次確認，之後可重建，歷程不刪除。今日撤銷留下 live hold：資料品質可按新版判讀，但不自行重開工作、恢復排程或補跑。未輸入的臨時休市不會自動偵測；此設定不等於官方即時確認，不用來表示個股停牌、半日市或強制開市。

## 本機共用資料檢查

| 用途 | 判定與限制 |
| --- | --- |
| 日 K／分 K | 休市列 excluded；休市卻有棒列 conflict；排定時段缺棒列缺漏候選。分 K 驗分鐘與邊界，不只數根數。盤中移動日 K 不當完整收盤。未排除上市前／停牌，不冒稱官方真缺棒。 |
| 法人／資券 | 按「資料日」而非今天，保留原 16:00／21:00 程式窗口（不是新取得的官方固定發布保證）。核現存商品列與同日、市場、dataset 的 receipt／映射。 |
| TDCC | 缺獨立期別／發布契約就 unknown；不能因單日休市略過整週。 |
| 量比監控 | 本筆既有入口共用 store 與日曆版本。前後交易日略過已設定休市；舊 D→T 與來源 hash 不因更正自動有效，缺新原始鏈仍阻擋。 |

「現有資料唯讀檢查」需明確按鈕才執行；只讀本機 MultiView 現成庫，單商品日 K 最長 367 日、分 K 最長 7 日／5,000 列，籌碼每次一個資料日。無持久分 K、來源過期或資料不足都 unknown。結果列版本、真正核對時間、缺漏／排除／衝突、外部請求與是否寫入。

此按鈕不接資料取得、collector、修復器或健康檢查，不改原圖表來源／官方稽核收據，也不把新結果冒充所有提供者已驗。原圖表抓取或獨立 pipeline 非本按鈕副作用；修改條件／設定後須重新檢查，不沿用舊結果。只有 local adapter 接入，兩站不採用本機設定。

## 程式處理的範圍

本筆守門涵蓋既有盤前、盤後／重試、失敗稽核、晚登入及採集派送、比較／通知節點，讀取同一份本機設定。尚未提交的 02:00 名單 final／動態執行整合屬其他批次。休市日零請求略過；設定損毀、權限錯誤或日期鏈不足時阻擋，不默認開市。

若開始後才輸入，後續新派送及比較會被阻擋；在途或已完成請求無法追回，原 partial／failed／claim／receipt 照實保留。程式不殺服務、不平倉、不清鎖、不補跑、不增加下載授權。這不是全產品所有交易／選股模組的全域緊急停止開關。

受影響的舊 D→T 不得改標為新日期；缺件期間保持阻擋，不以另一日期基準湊齊。未提交的 original／final／prepared 名單鏈仍由後續功能批次驗證。撤銷未來日期不會自動補執行錯過的時點。

## 儲存與來源

新設定在 App Support `MarketCalendar/special-closures/`，0700／0600、不可變追加、父 hash 及 expectedRevision CAS。舊 `IntradayMonitor/special-market-closures/` 唯讀相容，以原 hash／revision 起新鏈，不搬改原件。hash 鏈只證一致性，不是假稱抵抗本機管理員的簽章。不要直接刪除或手改歷程；無效歷程會阻擋。

有效日曆＝仍有效、已驗年度資料＋使用者指定市場休市；未列特殊休市不等於已證開市。年度過期／缺範圍／設定損毀都 unknown，不補猜或延效。API `/api/market-calendar/v1` 與舊監控設定路由共用 store；唯讀資料檢查只向固定 loopback Worker 傳送有界投影，不送兩站、不建立／遷移 DB。研究原文與舊收據不改寫。
